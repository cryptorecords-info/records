Data and contributions

Download the catalogue or suggest a correction.

Downloads

  • Comparison categories (.json)
  • Problems (.json)

Lists also offer JSON and CSV downloads. Source pages include BibTeX and individual result data.

Contribute

Add or correct papers in data/papers.bib and bounds in data/records/<category>.json. Cite the supporting theorem, table or source version and submit a pull request.

Use the downloadable dataset and contribution guide until the public repository is linked.

Comparisons

Each category fixes the problem, assumptions and cost scale. Only comparable bounds are ranked. History charts show strict improvements and mark other numerical results separately. Alternative techniques, lower memory and stronger guarantees are also included.

Source checked means the cited paper contains the attributed bound.
