Description
Arbitrary-width centered DGS with inverse-polynomial statistical accuracy.
Comparison rules
For any positive width, produce a distribution within 2^{-f(n)} of a pointwise (1+1/f(n))-multiplicative approximation. f is polynomial, so implied total-variation accuracy is inverse polynomial. Do not merge with negligible-error DGS without a separate argument.
