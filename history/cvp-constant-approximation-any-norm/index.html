Description
Constant-factor search CVP for arbitrary centrally symmetric convex norm balls, with the paper’s norm representation and oracle assumptions.
Comparison rules
For each fixed ε > 0 return a γ_ε-approximate closest vector for any norm and arbitrary rank-n lattice. The constant may depend on ε. Preserve norm representation, oracle precision and polynomial input-size factors. This differs from an exact-CVP guarantee and from constant factors fixed independently of ε.
