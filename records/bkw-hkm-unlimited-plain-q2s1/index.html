Selected earlier references

Selected sources cited by this paper.

  1. An Improved BKW Algorithm for LWE with Applications to Cryptography and Lattices

    Paul Kirchner · Pierre-Alain Fouque · 2015

    Uses the improved unlimited-sample analysis and examines its amplification proof. §7.1–7.2, reference [27]; §7.3

  2. Coded-BKW: Solving LWE Using Lattice Codes

    Qian Guo · Thomas Johansson · Paul Stankovski · 2015

    Credits an independently proposed first-phase BKW modification. §7.2, reference [22]

  3. On the Complexity of the BKW Algorithm on LWE

    Martin R. Albrecht · Carlos Cid · Jean-Charles Faugère · Robert Fitzpatrick · Ludovic Perret · 2015

    Explains the simplified search analysis’s parameter choice and presents the +1/2 refinement. §7.1, reference [4], after Equation (10)

  4. The Parity Problem in the Presence of Noise, Decoding Random Linear Codes, and the Subset Sum Problem

    Vadim Lyubashevsky · 2005

    Extends the polynomial-sample amplification idea from LPN to LWE. §7.3, reference [34]

  5. Noise-Tolerant Learning, the Parity Problem, and the Statistical Query Model

    Avrim Blum · Adam Kalai · Hal Wasserman · 2000

    Uses the original LPN BKW algorithm as the starting point. Introduction; §7, reference [13]
