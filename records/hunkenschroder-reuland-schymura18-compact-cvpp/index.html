CVP / Exact · polynomial-space query · compact basis

On compact representations of Voronoi cells of lattices

Christoph Hunkenschröder · Gina Reuland · Matthias Schymura

Mathematical Programming 2020

PublishedSource checked

Cost model
Deterministic exact CVPP; Voronoi-vector superset enumerated as needed

Assumptions and source notes

The gain is a polynomial-space representation and query algorithm, not a smaller unrestricted CVP time exponent. Every lattice has an n²-compact basis, but the source leaves efficient construction without computing the Voronoi cell as an open problem. All preprocessing needed to supply the basis is excluded from the query bound.

Source location

Corollary 4.1 and discussion following it; Theorem 2.4; Problem 4.2
