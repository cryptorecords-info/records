Assumptions and source notes

Corrected AKS analysis from the author PDF headed “Corrected version – 02/01/2013”. The exact day/month convention is not assumed; 31 December 2013 is the conservative year-only date. This is a later corrected analysis, not a new overall time record after PS09. The obsolete author PDF’s 3.346/2.173 pair is not imported.

Source location

Theorem 4.2, PDF p. 16; Appendix A, PDF p. 32
Version: Corrected version – 02/01/2013

Selected earlier references

Selected sources cited by this paper.

  1. Sieve Algorithms for the Shortest Vector Problem are Practical

    Phong Q. Nguyen · Thomas Vidick · 2008

    traces the earlier rigorous AKS constant analysis §4 introduction and reference [65]

  2. Faster exponential time algorithms for the shortest vector problem

    Daniele Micciancio · Panagiotis Voulgaris · 2010

    reanalyzes ListSieve and its bounds §4.2 and Appendix B, reference [58]

  3. Solving the Shortest Lattice Vector Problem in Time 2^(2.465n)

    Xavier Pujol · Damien Stehlé · 2009

    presents the ListSieve birthday refinement §4.2, Theorem 4.4 and Appendix B, reference [68]

  4. Improved Analysis of Kannan's Shortest Lattice Vector Algorithm

    Guillaume Hanrot · Damien Stehlé · 2007

    reviews the improved enumeration analysis Introduction and §5, reference [32]

  5. A Deterministic Single Exponential Time Algorithm for Most Lattice Problems Based on Voronoi Cell Computations

    Daniele Micciancio · Panagiotis Voulgaris · 2013

    already presents the 2^{2n} Voronoi bound before the 2012 ECCC revision Original uncorrected 2011 author PDF, introduction and Table 1 (PDF p. 3); §3.1 (PDF pp. 8–10); end of §3.2 (PDF p. 13)
