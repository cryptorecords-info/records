Assumptions and source notes

The same source gives a different rigorous ListSieve parameter choice using space 2^{1.095n} and still singly exponential time. No time coefficient is inferred for this space endpoint. It is an unranked time–space point, distinct from the 3.199/1.325 optimized-time point.
