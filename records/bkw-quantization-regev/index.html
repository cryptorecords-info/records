Assumptions and source notes

CRYPTO 2015. Rounded Regev specialization of progressive quantization; the asymptotic coefficient is (1/2 + 2 ln(4/3))⁻¹. This is an abundant-sample row, not the separate bounded-error subexponential theorem.

Selected earlier references

Selected sources cited by this paper.

  1. On the Complexity of the BKW Algorithm on LWE

    Martin R. Albrecht · Carlos Cid · Jean-Charles Faugère · Robert Fitzpatrick · Ludovic Perret · 2015

    Discusses the original LWE adaptation and its noise-growth analysis. §3.1, reference [4]; after Corollary 1

  2. Lazy Modulus Switching for the BKW Algorithm on LWE

    Martin R. Albrecht · Jean-Charles Faugère · Robert Fitzpatrick · Ludovic Perret · 2014

    Generalizes the lazy-modulus-switching viewpoint using stage-dependent quantization. §3.1, reference [5]

  3. An Improved LPN Algorithm

    Éric Levieil · Pierre-Alain Fouque · 2006

    Lists an earlier BKW improvement for the binary case. Introduction, reference [33]

  4. Noise-Tolerant Learning, the Parity Problem, and the Statistical Query Model

    Avrim Blum · Adam Kalai · Hal Wasserman · 2000

    Starts from the original blockwise Gaussian-elimination algorithm. §3.1, reference [12]
