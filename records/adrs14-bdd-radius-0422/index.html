Assumptions and source notes

The first arXiv version already contains this corollary. Above-smoothing Gaussian sampling supplies the dual-vector advice within the displayed total cost. The guarantee is radius (0.422−o(1)) lambda_1(L), not every radius below lambda_1(L)/2. Radius is an entry parameter, so this row is not numerically ranked against a bound for another decoding promise.

Source location
