Assumptions and source notes

A single exact-SVP bound valid for every fixed ℓp norm, 1 ≤ p ≤ ∞. Theorem 3.2 and the following optimization use γ = 0.598 and ξ = 0.82. This row is dated to the checked v3; the numerical all-norm coefficient is not assumed to have appeared in the 2019 first version. It is not an improvement over the special Euclidean bound.
