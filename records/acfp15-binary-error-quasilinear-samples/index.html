LWE / Binary error · conditional algebraic bounds

Algebraic Algorithms for LWE

Martin R. Albrecht · Carlos Cid · Jean-Charles Faugère · Ludovic Perret

ePrint 2014/1018

PreprintSource checked
Time bound
O(m² · 2ωn log₂log₂log₂(n)/(8log₂log₂(n)))
Space bound
O(m² · 22n log₂log₂log₂(n)/(8log₂log₂(n)))
Source / version date
26 Feb 2015
Comparison variant
Binary error · conditional algebraic bounds
Cost scale
Parameter-dependent time and space expressions
Parameters
Odd prime q=q(n), polynomially bounded; source regime m=O(n log log n); 2≤ω<3.
Error distribution
Independent uniform errors in {0,1}.
Secret distribution
Arbitrary s∈Z_q^n.
Sample budget
Quasilinear samples m=O(n log log n), as specified in Theorem 7(iv); not a claim for every smaller m.
Objective
Recover the secret via the generated quadratic equations.
Cost model
Field operations; dense linear-algebra exponent ω.
Assumptions
Assumption 2: semi-regularity.
Success guarantee
Conditional on semi-regularity and the intended unique-solution regime.

Assumptions and source notes

Conditional subexponential bound in a quasilinear-sample regime. The hidden sample-count constant must be retained when instantiating the result.

Source location

§6, Theorem 7(iv), Eq. (12), p. 13
Version: ePrint 2014/1018 revised 26 February 2015
