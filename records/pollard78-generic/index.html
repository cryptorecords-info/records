r is the prime subgroup order, not the finite-field cardinality.

Assumptions and source notes

Rho’s square-root running time uses a random-walk/random-function heuristic; storage is a constant number of group elements. The original paper formulates index computation modulo p; the generic group-operation formulation is its standard representation-independent specialization.
