Assumptions and source notes

The exact-SVP consequence is separate from the paper’s one-sample DGS theorem. Theorem 6.6 gives success probability at least 2/3, time coefficient c₀ = 1/2 + β_Lev²/(4e ln 2) ≈ 0.7315 and space coefficient 1/2 on every execution. This was not an overall time record: Hhan’s 0.6039 result had appeared the preceding day. Source checked; proof not independently audited.

Selected earlier references

Selected sources cited by this paper.

  1. Solving the Shortest Vector Problem in 2^n Time via Discrete Gaussian Sampling

    Divesh Aggarwal · Daniel Dadush · Oded Regev · Noah Stephens-Davidowitz · 2015

    Uses the older above-smoothing batch sampler on superlattices to obtain one arbitrary-width centered sample. Abstract; §1.2; Theorem 2.6

  2. Solving the Shortest Vector Problem in 2^(0.7314n+o(n)) Time via Discrete Gaussian Sampling on Superlattices

    Yiming Gao · Yansong Feng · Honggang Hu · 2026

    Independent superlattice-based exact-SVP result; compares 0.7314 with this paper’s 0.7315. §1, Concurrent work; bibliography [GFH26]

  3. Solving the Shortest Vector Problem in 2^(0.6039n) Time via Mid-point Hessian

    Minki Hhan · 2026

    Earlier Hessian approach already gives a smaller exact-SVP time exponent. §1, Concurrent work; bibliography [Hha26]

  4. Solving the Shortest Lattice Vector Problem in Time 2^(2.465n)

    Xavier Pujol · Damien Stehlé · 2009

    Uses the earlier lattice-point counting bound in the Gaussian-mass analysis. §6, Lemma 6.1 and bibliography [PS09]
