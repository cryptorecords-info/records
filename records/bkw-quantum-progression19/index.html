Selected earlier references

Selected sources cited by this paper.

  1. Coded-BKW with Sieving

    Qian Guo · Thomas Johansson · Erik Mårtensson · Paul Stankovski · 2017

    Analyzes the γ=1 variant of the earlier algorithm under four sample/computation settings. §III, reference [13]; §VI, Table I

  2. On the Asymptotics of Solving the LWE Problem Using Coded-BKW with Sieving

    Qian Guo · Thomas Johansson · Erik Mårtensson · Paul Stankovski Wagner · 2019

    Restates the earlier common-factor analysis before extending the reduction schedule. §III, reference [14]; Theorem 1

  3. An Improved BKW Algorithm for LWE with Applications to Cryptography and Lattices

    Paul Kirchner · Pierre-Alain Fouque · 2015

    Identifies prior progressive quantization in the BKW history. §III, reference [12]; §V.C

  4. Coded-BKW: Solving LWE Using Lattice Codes

    Qian Guo · Thomas Johansson · Paul Stankovski · 2015

    Identifies independently developed lattice-code BKW reduction. §III, reference [11]; §V.C

  5. On the Complexity of the BKW Algorithm on LWE

    Martin R. Albrecht · Carlos Cid · Jean-Charles Faugère · Robert Fitzpatrick · Ludovic Perret · 2015

    Discusses the original detailed BKW analysis for LWE. §III, reference [9]; §V.B

  6. Noise-Tolerant Learning, the Parity Problem, and the Statistical Query Model

    Avrim Blum · Adam Kalai · Hal Wasserman · 2000

    Traces the original BKW algorithm to STOC 2000. §III, reference [8]
