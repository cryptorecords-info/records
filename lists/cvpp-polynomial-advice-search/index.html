Description
History of approximation factors when unbounded lattice preprocessing is allowed but its advice and the online algorithm are polynomial.
Comparison rules
Return a lattice vector within factor γ(n) of optimal for every target. Preprocessing depends only on the lattice and is not charged as query time. Record advice size separately. A polynomial query bound has no numeric 2^{cn} score. Distance estimation and bounded-distance promises belong in separate variants.
