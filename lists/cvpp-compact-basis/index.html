Description
Exact closest-vector queries using a compact representation of the Voronoi-relevant vectors.
Comparison rules
A supplied basis is c-compact if every Voronoi-relevant vector has basis coordinates bounded in absolute value by c. Count online query time and polynomial working storage. Constructing the compact basis is preprocessing and is excluded; the existence of a compact basis does not imply an efficient preprocessing algorithm. Keep c explicit and do not infer a numeric exponent from asymptotic notation.
