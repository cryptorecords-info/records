Description
Quantum upper bounds for exact Euclidean SVP on arbitrary lattices. Each result retains its memory and access model.
Comparison rules
Return an exact shortest vector on arbitrary full-rank lattices. The general list allows quantum random access where stated; it is not a no-QRAM ranking. Record classical memory, coherent access and quantum memory assumptions per result. The separate no-QRAM category excludes algorithms requiring quantum access to an exponential database. Publication, source checking and independent proof review are separate metadata.
