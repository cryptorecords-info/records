Comparison rules
For the radius alpha stated by each entry, return the nearest lattice point for targets satisfying dist(t,L) ≤ alpha lambda_1(L). Count every preprocessing and advice-construction step in total time. Do not rank bounds for different radii as a common numerical leaderboard. Keep supplied-basis, unbounded-preprocessing query and polynomial-advice models separate.
