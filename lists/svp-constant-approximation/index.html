Description
Leading time coefficients for constant-factor SVP families. The approximation constant may depend on the allowed exponent slack.
Comparison rules
For each fixed ε > 0, find a μ(ε)-approximate nonzero vector for some constant μ(ε). Compare c under these quantifiers only. A limiting coefficient is not a fixed-factor exact-SVP bound. Exact algorithms also qualify, and such transferred guarantees are identified in the notes.
