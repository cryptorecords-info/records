Description
Quantum full-distance ISD with the source memory and oracle model attached.
Comparison rules
Use random binary linear codes of rate R=k/n, error weight n H₂⁻¹(1−R), and maximize the exponent over 0≤R≤1. The parameter n is code length. Keep half-distance and fixed-rate bounds separate. Historical coefficients are rounded as in their cited sources; they are upper bounds, not claimed optimal values. Quantum-walk entries charge the setup/update/check model of the source. These are not claims for a memory-free quantum circuit model.
