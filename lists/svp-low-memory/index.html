Comparison rules
Only compare variants using space 2^{(½log₂(4/3)+o(1))n}, up to the displayed rounding of 0.2075/0.208. Extra hash tables must fit the same exponent. Unknown-space variants do not automatically qualify. The sieve-distribution heuristic remains an assumption.
