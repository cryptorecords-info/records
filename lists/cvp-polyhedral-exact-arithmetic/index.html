Description
Exact CVP for a norm ball described by rational linear inequalities; the input-size factor includes its constraints.
Comparison rules
Given a rational centrally symmetric full-dimensional polytope with s inequalities, a rational full-rank lattice and a target in its span, return a closest vector in the induced norm. Count arithmetic operations; keep the polynomial factor in s and the coefficient bit length explicit. This is a polyhedral-norm guarantee, not a result for an arbitrary oracle norm.
